# 按时吃药 · Medicine Reminder

一个注重隐私的用药提醒渐进式网页应用，目前版本为 **v0.3**。

## v0.3 功能

- 每种药支持最多 4 个提醒时间
- 支持每天、工作日或自定义星期重复
- 每条提醒可单独暂停和恢复
- 锁屏通知支持隐私模式，不显示具体药名
- 显示通知权限状态
- 保存最近 100 条服药历史
- 一键清除全部本地数据
- 可安装到安卓桌面并支持离线打开

## 数据与隐私

所有提醒、设置和服药记录只保存在当前浏览器的本地存储中，不上传服务器。隐私模式下，系统通知只显示通用提醒文案。

## 使用方法

通过 GitHub Pages 的 HTTPS 地址打开。在安卓 Chrome 中选择“安装应用”或“添加到主屏幕”。

> v0.3 网页版的定时检查仍依赖页面保持运行。

## Android v0.4

`android/` 中包含独立的原生安卓测试版，使用 Java 和 Android 系统组件实现：

- App 关闭后仍由系统保存服药闹钟
- 支持指定星期重复、启用和暂停
- 通知操作支持“我已服用”和“5 分钟后”
- 手机重启或 App 更新后恢复提醒
- 默认隐藏锁屏通知中的药名和备注
- 数据只写入 App 私有存储，禁用系统备份
- GitHub Actions 自动编译测试 APK

安卓测试版需要 Android 8.0 或更高版本。首次使用时应允许通知和“闹钟与提醒”权限，以获得更准时的后台通知。

### Android v0.5 开发版

0.5 在原生提醒基础上新增：

- 同一种药支持多个独立提醒时间
- 编辑已有药品、时间和重复日期
- 首页显示下一次提醒日期与时间
- 记录“已服用”和“已延后”操作
- 一键发送测试通知
- 更清楚的通知与准时提醒权限诊断
- 自动迁移 v0.4 的单时间本地数据
