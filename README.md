# 按时吃药 · Medicine Reminder

一个注重隐私的用药提醒渐进式网页应用，目前版本为 **v0.3**。

## v0.3 功能

- 每种药支持最多 4 个提醒时间
- 支持每天、工作日或自定义星期重复
- 每条提醒可单独暂停和恢复
- 锁屏通知支持隐私模式，不显示具体药名
- 显示通知权限状态
- 保存最近 100 条服药历史
- 一键清除全部本地数据
- 可安装到安卓桌面并支持离线打开

## 数据与隐私

所有提醒、设置和服药记录只保存在当前浏览器的本地存储中，不上传服务器。隐私模式下，系统通知只显示通用提醒文案。

## 使用方法

通过 GitHub Pages 的 HTTPS 地址打开。在安卓 Chrome 中选择“安装应用”或“添加到主屏幕”。

> v0.3 的定时检查仍依赖页面保持运行。安卓系统彻底停止浏览器后，提醒可能不会触发；后续原生 APK 版本会使用系统级后台闹钟。
