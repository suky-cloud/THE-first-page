# 按时吃药 · Medicine Reminder

一个简单的用药提醒渐进式网页应用，目前版本为 **v0.2**。

## 功能

- 添加药品名称、服药时间和备注
- 到点显示页面弹窗
- 可选择开启浏览器系统通知
- 支持“已服用”和“5 分钟后提醒”
- 使用浏览器本地存储保存提醒
- 手机和电脑屏幕均可使用
- 可安装到安卓手机桌面
- 安装后支持离线打开
- 提供测试弹窗按钮

## 使用方法

推荐通过 GitHub Pages 的 HTTPS 地址打开。在安卓 Chrome 中选择“安装应用”或“添加到主屏幕”，即可像普通 App 一样从桌面启动。

> v0.2 的定时检查仍依赖页面保持运行。安卓系统彻底停止浏览器后，提醒可能不会触发；后续原生 APK 版本会加入系统级后台提醒。
