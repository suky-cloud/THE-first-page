# 0.6 OCR 识别计划

## 目标

扫描药盒或药品说明上的文字，帮助用户快速填写药品名称和备注。0.6 首版只做“识别后确认”，不会自动保存，避免误识别直接变成提醒。

## 隐私设计

- 使用手机端本地 OCR，照片不上传服务器。
- 扫描完成后默认删除临时照片；用户主动保存时才保留。
- 识别结果先展示给用户编辑和确认。
- 锁屏通知继续使用隐私模式，不显示药品名称。

## 首版流程

1. 点击“扫描药盒”。
2. 请求相机权限并拍照。
3. 本地识别药品名称、规格和用法文字。
4. 把结果填入新增提醒表单。
5. 用户确认药名、时间和重复日期后保存。

## 暂不自动判断

OCR 只能读取文字，不能可靠判断剂量、禁忌或医生处方。0.6 不会根据识别文字自动生成医疗建议。
